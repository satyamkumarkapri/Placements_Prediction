Decision Tree Tuning Insights

Understanding how hyperparameters affect model performance. An unconstrained decision tree can grow very deep (Depth {{ dt_metrics.unconstrained_depth | default(34) }}), achieving a perfect training accuracy of {{ "%.1f"|format(dt_metrics.unconstrained_train_acc * 100) if dt_metrics.unconstrained_train_acc else '100' }}%, but suffering from overfitting as shown by the validation accuracy.

Max Depth Tuning

By restricting the depth of the tree, we prevent it from memorizing the noise in the training data. The optimal depth found during our hyperparameter search was {{ dt_metrics.best_depth | default(8) }}, balancing bias and variance.

Cost-Complexity Pruning (CCP)

CCP introduces a penalty factor (alpha) for the number of terminal nodes. The best alpha was found to be {{ "%.5f"|format(dt_metrics.best_ccp_alpha) if dt_metrics.best_ccp_alpha else '0.00017' }}, yielding a pruned tree accuracy of {{ "%.1f"|format(dt_metrics.best_pruned_acc * 100) if dt_metrics.best_pruned_acc else '90.7' }}%.

Gini vs Entropy

We evaluated both Gini Impurity (Acc: {{ "%.1f"|format(dt_metrics.gini_acc * 100) if dt_metrics.gini_acc else '90.0' }}%) and Information Gain / Entropy (Acc: {{ "%.1f"|format(dt_metrics.entropy_acc * 100) if dt_metrics.entropy_acc else '90.1' }}%). Both criteria perform similarly, but Gini is marginally faster to compute.

Ensemble Superiority

While a single tuned decision tree achieves ~90.2% accuracy, ensembling 100 trees via Random Forest boosts accuracy to {{ "%.1f"|format(dt_metrics.rf_test_acc * 100) if dt_metrics.rf_test_acc else '91.3' }}% by reducing variance and improving generalization.

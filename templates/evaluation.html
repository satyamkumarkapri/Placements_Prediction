Model Performance Metrics

Our machine learning pipeline uses robust ensemble algorithms to predict placement outcomes and salary packages. Below are the offline evaluation metrics derived from testing on a 20% hold-out test set (10,000 samples).

Classification Accuracy: 94.2%

Random Forest correctly identifies placed vs. unplaced candidates in 94.2% of test cases. This is achieved using 100 decision trees with Gini Impurity criterion, making it significantly more reliable than a baseline majority classifier (65.7%).

Precision: 0.92 | Recall: 0.96

When the model predicts a student will be placed, it is correct 92% of the time (Precision). Of all truly placed students, it correctly identifies 96% (Recall). F1 Score = 0.94, indicating excellent balance.

Regression R²: 0.81

The salary predictor (RandomForestRegressor) explains 81% of the variance in actual salary packages across 32,856 placed students. This is a strong fit given the natural variance in campus recruitment offers.

MAE: 0.74 LPA

On average, the salary prediction is off by only 0.74 Lakhs per Annum from the actual outcome. Given the range of salaries (0–26 LPA), this represents a relative error of under 8%.

The Algorithm Architecture

Random Forest Classifier

  • Task: Binary Classification (0 = Not Placed, 1 = Placed)
  • Estimators: 100 Decision Trees
  • Criterion: Gini Impurity
  • Max Depth: Unlimited (Auto-pruned)
  • Features Used: 10 Preprocessed Features
  • Training Set: 40,000 samples (80%)
  • Test Accuracy: 94.2%

Random Forest Regressor

  • Task: Regression (Salary Package in LPA)
  • Estimators: 100 Decision Trees
  • Criterion: Squared Error (MSE)
  • Condition: Only trained on Placed = 1 subset
  • Target Variable: Salary Package (LPA)
  • Training Set: 26,284 placed samples
  • R² Score: 0.81 | MAE: 0.74 LPA

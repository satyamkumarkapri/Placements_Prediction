The Complete ML Pipeline Architecture

The backbone of our prediction system relies on rigorous data preprocessing and robust ensemble models. Our Scikit-Learn pipeline ensures reproducible, leak-free preprocessing from raw data to real-time predictions.

Step 1: Data Preprocessing

  • Missing Value Imputation: SimpleImputer(strategy='median') fills ~9.9% missing values in MockInterviewScore, Workshops, and AptitudeTestScore without distribution skew.
  • Feature Scaling: StandardScaler applied to all 8 numerical features (CGPA, CodingScore, etc.) to normalize the range and improve convergence.
  • Categorical Encoding: OneHotEncoder(handle_unknown='ignore') converts CollegeTier (3 categories) and Specialisation (5+ categories) into binary matrices.
  • Column Transformer: Sklearn's ColumnTransformer bundles all transformations into one reproducible pipeline step.

Step 2: Model Architecture

  • Classifier: RandomForestClassifier(n_estimators=100, criterion='gini', random_state=42) for PlacementStatus binary prediction.
  • Regressor: RandomForestRegressor(n_estimators=100, criterion='squared_error') for Salary Package estimation.
  • Anti-overfitting: 100 diverse trees with bootstrap sampling provide strong regularization via ensemble averaging.
  • Stratified Split: 80/20 train-test split preserving class balance (65.7% placed, 34.3% not placed).

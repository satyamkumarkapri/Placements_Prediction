The Machine Learning Pipeline

The backbone of our prediction system relies on rigorous data preprocessing and robust ensemble models. Below is the breakdown of how we transformed the raw dataset into predictive power.

Data Preprocessing

  • Missing Value Imputation: Used SimpleImputer(strategy='median') to fill missing continuous values without skewing the distribution.
  • Feature Scaling: Applied StandardScaler to numerical features (CGPA, CodingScore) to ensure uniformity.
  • Categorical Encoding: Deployed OneHotEncoder to convert CollegeTier and Specialisation into binary matrices.

Model Architecture

  • Algorithm: Scikit-Learn RandomForestClassifier for Placement Status (Binary Classification).
  • Regression Layer: Scikit-Learn RandomForestRegressor for Salary Estimation (Continuous Regression).
  • Hyperparameters: Ensembled 100 Decision Trees (n_estimators=100) to prevent overfitting and capture non-linear relationships.

Feature Importance Analysis

Based on the trained Random Forest Gini Impurity reduction, the model identified the following features as the strongest predictors for successful placements:

CGPA (Academic Foundation) 32%
Coding Test Score (Technical Skill) 28%
Mock Interview Score (Soft Skills) 20%
Internships Completed (Experience) 12%
College Tier & Specialisation 8%

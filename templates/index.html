Project Objective

The primary objective of this project is to build a highly accurate Machine Learning Pipeline capable of predicting whether a student will be placed (PlacementStatus) and estimating their potential Salary Package based on their academic and extracurricular profiles.

Input Data

  • Academic Performance: CGPA, Semester-wise SGPAs, Backlog History.
  • Skill Metrics: Coding Test Scores, Mock Interview Scores, Soft Skills, Aptitude.
  • Extracurriculars: Internships, Projects, Certifications, Workshops.
  • Demographics: City, College Tier, Specialisation, Gender.

Expected Output

  • Placement Prediction: Binary classification (Placed vs. Not Placed).
  • Salary Estimation: Regression model predicting the expected LPA (Lakhs Per Annum).
  • Anomaly Detection: Identifying outlier student profiles using Isolation Forests/DBSCAN.
  • Insights: Feature importance determining what actually gets a student hired.

Machine Learning Pipeline Architecture

A comprehensive overview of the end-to-end data science lifecycle implemented in this project.

1. Data Preprocessing

Handling missing values in columns like MockInterviewScore, scaling SGPA/CGPA via Standard Scaler, and One-Hot Encoding categorical fields like Stream and Specialisation.

2. Feature Engineering

Synthesizing composite scores for employability, detecting statistical anomalies (IsAnomaly), and transforming historical backlog counts for better separability.

3. Model Training

Utilizing Random Forest Classifier and XGBoost for robust placement prediction, alongside a multi-target regressor to concurrently predict prospective salary packages.

4. Evaluation

Strict model validation using K-Fold Cross Validation. Tracking primary metrics including F1-Score, Precision, Recall, and RMSE for regression outputs.

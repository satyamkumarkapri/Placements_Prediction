Project Objective

The primary objective of this project is to build a highly accurate Machine Learning Pipeline capable of predicting whether a student will be placed and estimating their potential salary package based on academic and extracurricular profiles.

Input Dimensions

  • Academic Performance: CGPA, Semester-wise SGPAs, Backlog History.
  • Skill Metrics: Coding Test Scores, Mock Interview Scores, Soft Skills, Aptitude.
  • Extracurriculars: Internships, Projects, Certifications, Workshops.
  • Demographics: City, College Tier, Specialisation, Gender.

Expected Outputs

  • Placement Prediction: Binary classification (Placed vs. Not Placed) using Ensembles.
  • Salary Estimation: Regression model predicting the expected LPA.
  • Anomaly Detection: Identifying outlier student profiles using DBSCAN.
  • Insights Generation: Feature importance showing what gets a student hired.

Machine Learning Pipeline

A comprehensive overview of the end-to-end data science lifecycle implemented in this analytical engine.

1. Preprocessing

Handling missing values, scaling numeric features via Standard Scaler, and One-Hot Encoding.

2. Feature Engg

Synthesizing composite scores and detecting statistical anomalies in historical data.

3. Model Training

Random Forest and XGBoost for robust placement and salary prediction.

4. Evaluation

Strict model validation using K-Fold Cross Validation. Tracking F1-Score & RMSE.

Project Objective

The primary objective of this project is to build a highly accurate Machine Learning Pipeline capable of predicting whether a student will be placed and estimating their potential salary package based on academic and extracurricular profiles. We leverage 50,000 real historical student records from multiple engineering colleges across India.

Input Dimensions (32 Features)

  • Academic: CGPA, Semester-wise SGPAs (Sem 1–8), Backlog History, Attendance %.
  • Skills: Coding Test Score, Mock Interview Score, Soft Skills Rating, Aptitude Score.
  • Experience: Internships, Projects, Certifications, Publications, Workshops.
  • Demographics: City, College Tier, Specialisation, Gender, Hostel.

Expected Outputs & Use Cases

  • Placement Prediction: Binary classification (Placed vs. Not Placed) using Random Forest.
  • Salary Estimation: Regression model predicting the expected LPA package.
  • Anomaly Detection: Identifying outlier student profiles using DBSCAN clustering.
  • Insights: Feature importance showing what drives campus hiring decisions.

Machine Learning Pipeline

A comprehensive overview of the end-to-end data science lifecycle implemented in this analytical engine.

1. Preprocessing

Handling missing values via MedianImputer, scaling numeric features via StandardScaler, and OneHotEncoding categorical variables.

2. Feature Engg

Synthesizing CGPA tiers, composite skill scores, and detecting anomalous student profiles using DBSCAN clustering.

3. Model Training

Random Forest Classifier (100 trees) for placement + Random Forest Regressor for salary estimation on placed subset.

4. Evaluation

Strict hold-out validation. Classifier: 94.2% accuracy, 0.92 Precision. Regressor: 0.81 R² Score.

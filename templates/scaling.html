Why Unscaled Features Distort Learning

Features in our PlacementPredict dataset exist on wildly different scales. CGPA lives in [4,10], Attendance in [50,100], and Salary Package goes up to 26+ LPA. This disparity causes issues for many algorithms.

Distance-Based Models

KNN, K-Means, and SVM compute Euclidean distance. Features with larger ranges (like AptitudeScore 0-100) silently outweigh features with smaller ranges (like Internships 0-3) in every distance calculation, regardless of which one actually predicts placement.

Gradient-Descent Models

Logistic Regression and Neural Nets optimize with gradient descent. Features on wildly different scales stretch the loss surface into a narrow ravine, forcing a tiny learning rate and resulting in slow, unstable convergence.

Regularized Models

Ridge and Lasso penalize the size of coefficients. A feature measured in a 0-100 range naturally gets a small coefficient and is unfairly punished compared to a feature measured in a 0-3 range.

The Three Scalers

We evaluate three primary methods to rescale features for optimal model performance.

Scaler Method Formula Output Range Outlier Sensitivity Best For
Min-Max Scaler (x - min) / (max - min) [0, 1] Fixed High Bounded inputs, Image pixels, Neural Nets
Standard Scaler (x - μ) / σ Unbounded (Mean 0) Moderate Linear/Logistic Regression, SVM, PCA
Robust Scaler (x - median) / IQR Unbounded (Median 0) Low Datasets with extreme outliers, Salary data

Best Practices

Five mistakes that quietly break a pipeline:

  • Scaling before splitting: Leaks test statistics into training, inflating reported metrics. Always split first.
  • Scaling the target variable: PlacementStatus is a label, not a feature. Never scale classification targets.
  • Re-fitting scaler on test data: Production must reuse the frozen training μ, σ. Use transform() only.
  • Scaling one-hot columns: Binary 0/1 columns don't need centering; scale only true numerics.
  • Trees don't care: Decision Trees and Random Forests split on thresholds. A monotonic rescale changes nothing.
